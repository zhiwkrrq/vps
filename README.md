## 年付之前必须先定的四个变量

香港只是"地区"，同一个地区下不同区域的线路、带宽、库存完全不是一回事。年付锁十二个月之前，先看这四件事：

1. **线路类型**。香港节点常见的有三网精品（CN2+CMI+CUG）、移动CMI优化、国际大带宽混合线路。线路决定大陆访问的延迟和绕路情况，比CPU型号重要得多。
2. **限流量型还是不限流量型**。雨云同一配置同时提供两种：大带宽+每月固定流量，或者小带宽+不限流量，价格一样。流量用完后统一限速到5Mbps，之后可以买流量包恢复。
3. **区域库存**。香港二区、三区、四区、五区不是随时都有货，二区就出现过售罄的情况。年付最好在确认有货的区域下单。
4. **附加项费用**。默认含1个IPv4，额外IP一般5元/个/月；香港移动高防IP约40元/月，香港国际高防IP约30元/月；硬盘标配30GB，可弹性扩容。这些都不含在标价里，年付预算要把它们加进去。
